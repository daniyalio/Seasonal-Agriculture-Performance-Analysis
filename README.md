# Seasonal Agriculture Performance Analysis

## Project overview

This is a beginner-friendly but detailed data analysis project based on the VOIS major project brief.

The project studies agricultural performance across the Kharif, Rabi and Zaid seasons. It uses information about farms, crops, states, rainfall, temperature, soil, irrigation, yield, production, cost, revenue, profit, water use and disease or pest risk.

The main aim is to understand how agricultural results change by season and how crop choice, location and irrigation method are related to farm performance.

## Main project findings

The analysis shows that:

- Kharif has the highest average yield and average profit in this dataset.
- Zaid has the lowest average disease and pest risk.
- Sugarcane has the highest average profit among the crops.
- Crop, state, season and irrigation method show differences in farm performance.
- Rainfed farms have the highest average water efficiency in this dataset.

These are observations from the supplied data and should not be treated as proof of cause and effect.
